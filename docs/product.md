# Product

## Overview
A Multi-Agent & User Context Sync Platform enabling AI models (Claude, ChatGPT, Gemini, Grok) and human operators to store, retrieve, and synchronize structured working memory across Google Drive and GitHub using a Book-Style Context System and Model Context Protocol (MCP).

## Core Value Prop
Eliminates context loss, state collisions, and fragmented memories across multi-agent workflows by treating context like an indexed, readable book (`index.md`, `notice.md`, `commit.md`, and hierarchical folders) with granular MCP file/folder tools and verified cloud persistence.

## Target User(s)
- AI Engineers & Developers orchestrating multi-agent systems.
- Teams utilizing autonomous AI pair programmers needing persistent cross-session knowledge bases.
- Individual developers maintaining unified AI memory trees in private Google Drive and GitHub repositories.

## Scope Boundaries
- **Not a General Cloud Storage Client**: Does not aim to replace full Google Drive or Dropbox desktop clients for arbitrary media files.
- **Not a Chat Interface Clone**: Focuses strictly on context storage, file/folder hierarchy, MCP synchronization, and memory management rather than conversational chatbot frontends.
